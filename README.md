# 激流数智

DeepSeek Harness 组织管理套件，包含数字人、数据监控、AI 视频工坊、解析能力与 IM 机器人。

## 下载

前往 [Releases 下载最新版](https://github.com/qitao3344/jiliu-shuzhi/releases/latest)。Windows 用户下载 `jiliu-shuzhi-0.8.25-windows-public.zip`，解压后先阅读“先看这里.txt”。

## 0.8.25 数字人共享修复

旧版只共享组织权限，数字人的配置与素材仍由各电脑单独读取。本版将页面和工具接入组织服务，成员使用管理端已有的形象、音色、算力池与渠道；密钥保留在管理端，成员作品与私人音频按身份隔离。

管理端和成员端均需升级总套件 **0.8.25** 和数字人 **0.2.5**，完全退出并重开 DSH，连接同一组织，管理端保持在线。管理员需在“应用管理 → 随包应用更新”登记、审核并发布数字人 0.2.5。成员电脑应填写管理端可达的地址。

公开发行包不包含私人监控迁移快照、真实组织配置或账号凭据；现有本机数据继续保留，新电脑使用空白监控数据。
